# Components

Small pieces any Builder can copy into their project. Each one lives in its own folder with a live demo and a README.

| Component | What it does | Live demo |
|---|---|---|
| [Paw button](paw-button/) | Furry dog paw that squashes, barks, and throws tennis balls or bones | [Try it](https://hechoenosa.github.io/zerotohero2026/components/paw-button/) |

## Add a component

1. Make a folder: `components/your-component/`
2. Put a working `index.html` in it, so it has a live demo
3. Add a `README.md`: what it does, how to change it
4. Add a row to the table above
